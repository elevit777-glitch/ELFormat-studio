### v1.13 — скачивание исходных файлов

Для Excel и Word в увеличенном просмотре предусмотрена отдельная кнопка скачивания редактируемого файла. По нажатию на изображение открывается только увеличенная картинка — браузер не может превратить её в Excel или Word. На локальной странице Safari может обрабатывать загрузки по-своему; как резервный способ файлы также находятся в распакованной папке рядом с index.html.


## Исправление скачивания в локальном Safari (1.14)
Кнопки Excel/Word/PowerPoint/PDF теперь создают Blob-файл из встроенных данных. Исходный текст Word также доступен прямо в сравнении «до/после». Если браузер заблокирует скачивание — все исходники лежат рядом с index.html, их можно открыть двойным щелчком в Finder.
