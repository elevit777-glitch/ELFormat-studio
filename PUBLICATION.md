# ELFormat — кандидат к публикации

Это статический сайт. Для GitHub Pages все файлы из этой папки должны лежать в выбранной папке публикации вместе, на одном уровне с index.html. Служебный файл `.nojekyll` включён.

## Публикация
1. Использовать отдельный **публичный** репозиторий ELFormat, не Project Katya (он приватный и содержит стратегические записи).
2. В репозитории загрузить содержимое этой папки в корень ветки main.
3. GitHub Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. Проверить настоящую ссылку Pages, работу миниатюр, скачивания файлов, мобильную навигацию и контактный блок.

## Обязательно перед публичной рекламой
В текущем контактном блоке **нет отправки формы или прямого контакта**: посетитель копирует описание и отправляет его в той переписке, где получил ссылку. Для самостоятельного поиска клиентов потребуется согласованный адрес электронной почты/мессенджер и отдельное изменение блока.

## Приватность и прозрачность
Не включать Project Katya, личные записи, черновики и реальные персональные данные. Excel, Word и B2B Pharma маркированы как демонстрационные. Метатег robots установлен в noindex,nofollow до утверждения рабочего канала для входящих заявок.
